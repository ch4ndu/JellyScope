Choose the shared media rows for signed-in launchers. Each user sees only available libraries. Apps, pins and settings stay on the device.

Media layout

An empty layout shows Apps and settings only.

Recently Added Movies, Episodes and Series use Date Created order and can be limited to a library. Episodes appear individually. Series lists newly added series, not older series with new episodes. Recently Added keeps Jellyfin's mixed, grouped latest results.

Newest items in library lists movies and episodes from the selected library. A library is required for that query.

Recently Released Movies, Episodes and Series require a library and use premiere date, newest first. Items without a known premiere date or with a future date are omitted, so a row may contain fewer items than its limit. Series uses the series premiere, not a new episode's premiere.
