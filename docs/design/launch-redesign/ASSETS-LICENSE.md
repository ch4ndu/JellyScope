# Asset Provenance And Licensing

All JellyScope-created visual assets checked into this repository were
generated with ChatGPT for this project. This includes launch artwork, Settings
glyphs, app icons, launcher layers, TV banners, top-shelf artwork, and their
resized or converted platform variants.

No third-party artwork, third-party trademarks, real people, or real library
artwork was intentionally included. The packaged Settings glyphs live as shared
code-native vectors in
[`SettingsIcons.kt`](../../../shared-ui/src/commonMain/kotlin/com/jellyscope/ui/screen/settings/SettingsIcons.kt).

This file records asset provenance. The project license and the separate rules
for product-identity assets are defined in
[`licensing-and-distribution.md`](../../operations/licensing-and-distribution.md).
